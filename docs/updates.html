03 / established semantics, explicit limits
A trace to inspect.
A result to check.
Six declared atoms, eight fixed positive rules and at most eight fact transactions. Empty-body rules are true; duplicate rules retain their indices. No negation, tuple relations, variables, full Datalog syntax, rule updates or production performance claim.
This is a transparent positive, single-stratum delete/rederive specialization. It conservatively propagates overdeletion through rules that held in the old closure. Surviving facts and rules seed rederivation; delta insertion propagates only consequences touched by the latest additions.
The local-support contrast counts explicit membership plus currently firing indexed rules. Those counts are not numbers of finite proof trees. This deliberately weaker pruning control is not the published Counting algorithm or modern recursive counting methods.
The separate Python checker reconstructs each phase with sets and compares every final result with the intersection of all definite-Horn models. It shares strict input validation, not the generator. The browser engine is another generator, not an independent verifier.
