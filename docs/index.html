03 / complete finite truth table
A model can justify itself.
A proof must start somewhere.
A supported model equals initial facts plus heads whose bodies hold in that model. Circular justification can satisfy this equation. Only the least model captures positive atomic entailment. There is always an all-true model in this definite-Horn fragment.


04 / alternative support families
One derivation.
Every minimal seed set.
Supports retain rules and vary only the supplied initial facts. Minimal means no proper subset suffices, not smallest cardinality. Empty support can derive from an empty-body rule. Single-deletion failures certify inclusion-minimality because positive inference is monotone. These are seed sets, not all proof trees, rule provenance or causes.
