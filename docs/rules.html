Fixed facts / indexed rule subsets

One broken route.
Another still works.

Find every minimal rule support.
Then break every route.

The default goal has two minimal supports of different sizes. Deleting one route is not enough: every minimal deletion set must hit both. A self-cycle supplies no extra proof. Initial facts stay fixed.

01 / original synthetic controls

Keep the seeds.
Change only rules.

At most six atoms, eight indexed rules, 256 retained subsets and 65,536 UTF-8 input bytes. Duplicate rules are independent indexed choices. No negation, variables or external action.

02 / complete retained-rule lattice

Every subset.
Every closure.

Each synchronous round reads the previous set. The final empty added set records stability. A closure contains all fixed facts even when no rules remain.

03 / support versus deletion

Minimal is not
minimum size.

A fixed initial fact has empty rule support and cannot be broken by rule deletion. An atom already absent under all rules has no support and one empty deletion set: nothing needs to change. Neither convention asserts classical falsity.

04 / complete dual family

Hit every support.
Miss no alternative.

Minimal hitting sets of supports are exactly the minimal deletion sets; minimal hitting sets of deletion sets recover the supports. An empty family has one minimal hitting set, the empty set. A family containing the empty set has no hitting set. Every displayed pair has a nonempty intersection when both families exist. This is established finite-set duality, not causal attribution or a new diagnosis algorithm.

05 / full export and native replay

Verify the lattice.
Not just the winner.

Complete rule report JSON
python -m hornlab --rules examples/cycle.json -o rules.json
python -m hornlab --rules --verify rules.json
The separate native checker rebuilds synchronous closures with sets, cross-checks each subset against every classical assignment, checks all proper subsets for minimality and enumerates both hitting families. It never calls the generator. Shared input validation remains; no formal proof or signed certificate. The original inference and seed-support inspector is unchanged.
